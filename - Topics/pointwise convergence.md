## Source [^1]
- A sequence of functions $f_n : S \to \mathbb{R}$ on a given set $S$ converges pointwise if the real sequence $f_n(x)$ converges for all $x \in S$. This means for all $x$ in $S$ and for every $\varepsilon > 0$, there is an integer $N$ such that for all $m, n \ge N$ $|f_m(x) - f_n(x)| < \varepsilon$. Note that $N$ may depend on how both $x$ and $\varepsilon$ are defined. This is in contrast to uniform convergence, where, for any given $\varepsilon$, a single $N$ has to exist for all values of $x$.
