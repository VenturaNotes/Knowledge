## Source [^1]
- (monotone sequence) A real sequence $a_1, a_2, a_3, \dots$ is monotonic if it is either increasing, so $a_i \le a_{i+1}$ for all $i$, or decreasing, so $a_i \ge a_{i+1}$ for all $i$ and strictly monotonic if it is either strictly increasing or strictly decreasing. A bounded monotonic sequence converges.
