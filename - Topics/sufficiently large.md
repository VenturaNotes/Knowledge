## Source [^1]
- (sufficiently small) A proposition $P(x)$, where $x$ is a real number or natural number, is said to be true ‘for sufficiently large $x$’ if there exists $M$ such that $P(x)$ is true for all $x > M$. It may also be said that $P(x)$ is eventually true. Likewise, $P(x)$ is said to be true ‘for sufficiently small $x$’ if there exists $\varepsilon > 0$ such that $P(x)$ is true whenever $|x| < \varepsilon$.
