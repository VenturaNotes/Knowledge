## Source [^1]
- (measure theory) A subset of a measure space having measure zero. A subset $X$ of $\mathbb{R}$ is a null set if, for any $\varepsilon > 0$, there exists intervals $I_1, I_2, I_3, \dots$, of total length less than $\varepsilon$, such that $X$ is contained in the union of the $I_i$. Any countable set is null, and the Cantor set is an example of an uncountable null set.
