## Source [^1]
- (contains) If $A$ is a subset of the set $B$, that is, every element of $A$ is an element of $B$, then we say that 'A is contained in $B$' and that '$B$ contains $A$'. These are written $A \subseteq B$ and $B \supseteq A$. It is common, but technically incorrect, to say that $B$ contains $b$ when $b$ is an element of $B$.
