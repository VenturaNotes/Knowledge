## Source [^1]
- The nullity of a matrix $\mathbf{A}$ is the dimension of the solution space to the equation $\mathbf{Ax} = \mathbf{0}$; equivalently, it is the minimum number of parameters required to describe the system’s general solution. The general solution can be found by transforming the matrix into reduced echelon form and assigning a parameter to the variable of each column not containing a leading 1. See RANK-NULLITY THEOREM.
