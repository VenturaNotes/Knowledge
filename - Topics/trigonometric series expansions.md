## Source [^1]
- For $x$ measured in radians, the basic trigonometric functions sine and cosine can be expressed by the following series expansions, derived as Taylor series:$$\begin{aligned}\sin x &= x - \frac{x^3}{3!} + \frac{x^5}{5!} + \dots + (-1)^k \frac{x^{2k+1}}{(2k+1)!} + \dots, \\\cos x &= 1 - \frac{x^2}{2!} + \frac{x^4}{4!} + \dots + (-1)^k \frac{x^{2k}}{(2k)!} + \dots.\end{aligned}$$
- These series converge for all real and complex values of $x$.
