## Source [^1]
- A discrete uniform distribution is described by the probability function $P\left[X=x_{i}\right]=1 / N$, where the random variable $X$ can take values $x_{1}, \ldots, x_{N}$. A continuous uniform distribution is described by the probability density function $f_{X}(x)=1 /(b-a)$ where random variable $X$ can take values $x \in[a, b]$, and by the moment generating function $M(t)=\frac{\exp (b t)-\exp (a t)}{t(b-a)}$ for $t \neq 0$. The mean of continuous uniform distribution is $(b-a) / 2$ and the variance is $(b-a)^{2} / 12$.
## Source[^2]
- The uniform distribution on the interval $[a,b]$ is the continuous probability distribution whose probability density function $f$ is given by $f(x) = 1/(b - a)$, where $a \le x \le b$. It has mean $(a + b)/2$ and variance $(b - a)^2/12$. There is also a discrete form: on the set $1, 2, \dots, n$, it is the probability distribution whose probability mass function is given by $\Pr(X=r) = 1/n$, for $1 \le r \le n$. For example, the random variable for the winning number in a lottery has a uniform distribution on the set of all the numbers entered in the lottery.
