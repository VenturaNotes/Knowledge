## Source [^1]
- A square matrix $A$ such that $a_{i j}=a_{j i}$ for all $a_{i j}$ in $A$. Thus a symmetric matrix is equal to its transpose.
## Source[^2]
- Let $\mathbf{A}$ be the square matrix $[a_{ij}]$. Then $\mathbf{A}$ is symmetric if $\mathbf{A}^T = \mathbf{A}$ (see TRANSPOSE); that is, if $a_{ij} = a_{ji}$ for all $i$ and $j$.
