## Source [^1]
- (of a relation $R$ or function $f$ ) A relation or function obtained by restricting the domain of $R$ or $f$. If 'is the son of' is a relation defined on all the males in a certain country, a restriction would be this same relation defined on the males of a particular city.
## Source[^2]
- (of a function) For a function $f:X \to Y$ and a subset $A \subseteq X$, the restriction of $f$ to $A$ is the function, denoted $f|_A$, with domain $A$ and codomain $Y$, such that $f|_A(a) = f(a)$ for all $a$ in $A$. Thus, $f|_A$ is essentially the same assignment as $f$ but applied to a restricted set of inputs.
