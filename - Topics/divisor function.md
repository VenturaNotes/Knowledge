## Source [^1]
- The number of divisors of $n$, including 1 and $n$, denoted by $d(n)$. So $d(6) = 4$ since 1,2,3 and 6 are divisors of 6. For any prime number $p$, $d(p^k) = k + 1$. The divisor function is an arithmetic function which is multiplicative.
