## Source [^1]
- An element of a group, ring, etc. which is its own inverse, i.e. an element $a$ for which $a^2 = e$ where $e$ is the identity element. So the identity is always self-inverse; any reflection is self-inverse, as is a rotation through $180^\circ$.
