## Source [^1]
- A set $S$ in a topological space $X$ is dense if its closure is $X$. Informally, this means that every point in $X$ is either in $S$ or arbitrarily close to members of $S$. The set of rational numbers is dense in the space of real numbers. This can be appreciated by considering the truncated decimal representations of a real number.
