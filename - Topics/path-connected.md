## Source [^1]
- Describing a topological space (or metric space) $X$ in which there is a path between any two points; that is for any $x, y$ in $X$ there is a continuous function $f: [0, 1] \to X$ such that $f(0) = x$ and $f(1) = y$. Path-connected spaces are necessarily connected but the converse is not true.
