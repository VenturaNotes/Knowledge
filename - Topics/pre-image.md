## Source [^1]
- Given a function $f : X \to Y$ and $A \subseteq Y$, the pre-image $f^{-1}(A)$ of $A$ is$$f^{-1}(A) = \{x \in X \mid f(x) \in A\} \subseteq X.$$
- This notation does not imply that $f$ is invertible (see INVERTIBLE FUNCTION). Note $f(f^{-1}(A)) \subseteq A$, but equality does not generally hold.
