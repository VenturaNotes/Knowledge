## Source [^1]
- A subset $I$ of $\mathbb{R}$ is an interval if whenever $x < y < z$ and $x \in I, z \in I$, then $y \in I$.
- A \*bounded interval on the real line is a subset of $\mathbb{R}$ defined in terms of end-points $a$ and $b$. Since each end-point may or may not belong to the subset, there are four types of bounded interval:
	- (i) the closed interval $\{x \mid x \in \mathbb{R} \text{ and } a \le x \le b\}$, denoted by $[a, b]$,
	- (ii) the open interval $\{x \mid x \in \mathbb{R} \text{ and } a < x < b\}$, denoted by $(a, b)$,
	- (iii) the interval $\{x \mid x \in \mathbb{R} \text{ and } a \le x < b\}$, denoted by $[a, b)$,
	- (iv) the interval $\{x \mid x \in \mathbb{R} \text{ and } a < x \le b\}$, denoted by $(a, b]$.
- There are also four types of unbounded interval:
	- (v) $\{x \mid x \in \mathbb{R} \text{ and } a \le x\}$, denoted by $[a, \infty)$,
	- (vi) $\{x \mid x \in \mathbb{R} \text{ and } a < x\}$, denoted by $(a, \infty)$,
	- (vii) $\{x \mid x \in \mathbb{R} \text{ and } x \le a\}$, denoted by $(-\infty, a]$,
	- (viii) $\{x \mid x \in \mathbb{R} \text{ and } x < a\}$, denoted by $(-\infty, a)$.
- Here $\infty$ (read as 'infinity') and $-\infty$ (read as 'minus infinity') are not real numbers, but the use of these symbols provides a convenient notation.
