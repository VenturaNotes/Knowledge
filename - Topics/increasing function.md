## Source [^1]
- A real function $f$ is increasing on its domain $S$ if $f(x_1) \le f(x_2)$ whenever $x_1$ and $x_2$ are in $S$ with $x_1 \le x_2$. Also, $f$ is strictly increasing if $f(x_1) < f(x_2)$ whenever $x_1 < x_2$.
