- The real function $f$ of one variable is differentiable at $a$ if $\frac{f(a+h)-f(a)}{h}$ has a limit as $h \to 0$; that is, if the derivative of $f$ at $a$ exists. Informally a function is differentiable if it is possible to define the gradient of the graph $y = f(x)$ and hence define a tangent at the point. The function $f$ is differentiable in an open interval if it is differentiable at every point in the interval; and $f$ is differentiable on the closed interval $[a, b],$ where $a < b$, if it is differentiable in $(a,b)$ and if the right derivative of $f$ at $a$ and the left derivative of $f$ at $b$ exist.

- (differential) (multivariate case) A function $F: \mathbb{R}^n \to \mathbb{R}^m$ is differentiable at the point $\mathbf{p}$ in $\mathbb{R}^n$ if there exists a linear map $\text{d}F_{\mathbf{p}} : \mathbb{R}^n \to \mathbb{R}^m$ such that$$\lim_{h \to 0} \frac{F(\mathbf{p} + \mathbf{h}) - F(\mathbf{p}) - \text{d}F_{\mathbf{p}}(\mathbf{h})}{|\mathbf{h}|} = 0.$$$\text{d}F_{\mathbf{p}}$ is known as the differential (or derivative) of $F$ at $\mathbf{p}$. When $m = n = 1$, then $\text{d}F_{\mathbf{p}}$ is a $1 \times 1$ matrix with entry $F'(p)$. More generally $\text{d}F_{\mathbf{p}}$ is represented by the Jacobian matrix at $p$. A function $F: \mathbb{R}^n \to \mathbb{R}^m$ can be expanded as$$F(x_1, \dots, x_n) = (f_1(x_1, \dots, x_n), \dots, f_m(x_1, \dots, x_n)).$$
- It is sufficient for $F$ to be differentiable for all the partial derivatives $\partial f_i / \partial x_j$ to exist and be continuous (see CONTINUOUS FUNCTION). More generally, for a differentiable function $F: M \to N$ between smooth manifolds $M$ and $N$, the differential at $p$ in $M$ is a linear map $\text{d}F_p : T_p(M) \to T_{F(p)}(N)$ between tangent spaces. For $v$ in $T_p(M)$ take a curve $\gamma$ in $M$ such that $\gamma(0) = p$ and $\gamma'(0) = v$. Then $F(\gamma)$ is a curve in $N$ and $\text{d}F_p(v) = (F \circ \gamma)'(0)$.
