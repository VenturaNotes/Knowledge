## Source[^2]
- The relative error expressed as a percentage. When 1.9 is used as an approximation for 1.875, the relative error equals $0.025/1.875$ (or $0.025/1.9$) $= 0.013$, to 2 significant figures. So the percentage error is $1.3\%$, to 2 significant figures.
