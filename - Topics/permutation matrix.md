## Source [^1]
- A square matrix in which each column contains precisely one nonzero element, which is equal to unity. If $P$ is an $n$'$n$ permutation matrix and $\mathbf{x}$ is a vector of $n$ elements, the vector $P \mathbf{x}$ will be a permutation of the elements of $\mathbf{x}$.
## Source[^2]
- An $n \times n$ matrix with a single 1 in each row and each column and 0s everywhere else which can be used to represent a permutation of the $n$ objects in a set. For example, to map 1, 2, 3 to 1, 3, 2 the matrix$$\begin{pmatrix} 1 & 0 & 0 \\ 0 & 0 & 1 \\ 0 & 1 & 0 \end{pmatrix}$$would be used because$$\begin{pmatrix} 1 & 0 & 0 \\ 0 & 0 & 1 \\ 0 & 1 & 0 \end{pmatrix} \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix} = \begin{pmatrix} 1 \\ 3 \\ 2 \end{pmatrix}.$$
