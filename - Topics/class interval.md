## Source [^1]
- Numerical data may be grouped by dividing the set of possible values into class intervals and counting the number of observations in each interval. For example, if possible test marks lie in the range $0$ to $99$, groups could be defined by the intervals $0\textendash19, 20\textendash39, 40\textendash59, 60\textendash79$, and $80\textendash99$. It is often best (but not essential) to take the class intervals to be of equal widths.
