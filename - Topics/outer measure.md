## Source [^1]
- An outer measure on a set $X$ is a map $m^*$ from the power set of $X$ to $[0, \infty]$ such that
	- $m^*(\emptyset) = 0$;
	- $m^*$ is monotonic: if $A \subseteq B$, then $m^*(A) \le m^*(B)$;
	- $m^*$ is countably subadditive: $m^*(\bigcup_{k=1}^\infty A_k) \le \sum_{k=1}^\infty m^*(A_k)$.
- Given an outer measure $m^*$, a set $E$ is called Carathéodory measurable if$$ m^*(A) = m^*(A \cap E) + m^*(A \setminus E) $$for all subsets $A$ of $X$. The Carathéodory measurable sets form a sigma algebra on which $m^*$ is a measure.
