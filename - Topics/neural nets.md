## Source [^1]
- (neural networks) A neural net is a computational system loosely based on biological neural networks. A neural net consists of a connected set of nodes or neurons which can signal (that is, transmit real numbers) to adjacent nodes. The nodes and the edges connecting them are assigned weights which may change as 'learning' progresses by processing examples. Compare MACHINE LEARNING.
