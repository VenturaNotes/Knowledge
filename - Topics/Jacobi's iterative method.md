## Source [^1]
- A technique for solving a set of $n$ linear equations in $n$ unknowns. If the system is summarized by $\mathbf{Ax} = \mathbf{b}$, then taking initial values as $x_i^{(1)} = \frac{b_i}{a_{ii}}$, it uses the iterative relation$$x_i^{(k)} = \frac{b_i - \sum_{j \neq i} a_{ij} x_j^{(k-1)}}{a_{ii}}$$so it computes a complete set of new values together, unlike the Gauss–Seidel method.
