## Source [^1]
- A smooth vector field $\mathbf{v}$ along a parameterized curve $\gamma(t)$ in a surface $X$ is parallel if the covariant derivative $D\mathbf{v}/dt$ is zero. For a plane $X$, this means that $\mathbf{v}$ is constant. $\gamma(t)$ is a geodesic if and only if the tangent vectors $\gamma'(t)$ are parallel.
- If $\mathbf{v}$ is parallel and $t_1 < t_2$, then $\gamma(t_2)$ is the parallel transport of $\gamma(t_1)$ along $\gamma$.
