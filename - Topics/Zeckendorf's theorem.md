## Source [^1]
- Any integer $n \ge 1$ can be uniquely written as a sum of non-consecutive Fibonacci numbers 1,2,3,5,8,13,21,34,... For example, $300 = 233 + 55 + 8 + 3 + 1 = F_{13} + F_{10} + F_6 + F_4 + F_2$. See FIBONACCI ARITHMETIC.
