## Source [^1]
- (monotone function) A real function $f$ is monotonic on or a domain $I$ if it is either increasing on $I$, so $f(x_1) \le f(x_2)$ whenever $x_1 \le x_2$, or decreasing on $I$, so $f(x_1) \ge f(x_2)$ whenever $x_1 < x_2$. Also, $f$ is strictly monotonic if it is either strictly increasing or strictly decreasing.
