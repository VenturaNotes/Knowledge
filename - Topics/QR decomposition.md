## Source [^1]
- Any square matrix $\mathbf{M}$ can be decomposed as $\mathbf{M} = \mathbf{QR}$, where $\mathbf{Q}$ is orthogonal and $\mathbf{R}$ is upper triangular. If $\mathbf{M}$ is invertible, then this decomposition is unique if we require the diagonal entries of $\mathbf{R}$ to be positive, and the decomposition can be achieved by applying the Gram-Schmidt method to the columns of $\mathbf{M}$. Compare SINGULAR VALUE DECOMPOSITION.
