## Source [^1]
- A linear combination of vectors $v_1, \dots, v_k$ in a vector space is a sum of the form $a_1 v_1 + \dots + a_k v_k$, where $a_1, \dots, a_k$ are scalars in the base field. The span of a finite set of vectors is the set of linear combinations.
