## Source [^1]
- Given a function $f(x)$ on the interval $0 < x < L$ the Fourier cosine series is defined as$$\begin{align}&\frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos\left(\frac{n\pi x}{L}\right), \\&\text{where}\quad a_n = \frac{2}{L} \int_{0}^{L} f(x) \cos\left(\frac{nx}{L}\right) \text{ dx}.\end{align}$$
- This defines an even function of period $2L$.
