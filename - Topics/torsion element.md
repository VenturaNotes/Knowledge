## Source [^1]
- In a module $M$, over an integral domain $R$, an element $m \in M$ for which $r \cdot m = 0$ for some non-zero $r \in R$. The torsion elements of $M$ form the torsion submodule of $M$, and $M$ is said to be torsion-free if $0$ is the only torsion element. See STRUCTURE THEOREM.
