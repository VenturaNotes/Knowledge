## Source [^1]
- Given a real-valued function $f$ on a set $S$, a level set is a subset of $S$ of the form$$\{s \in S | f(s) = c\},$$for a given real constant $c$. For example, with $f(x, y, z) = x^2 + y^2 + z^2$, the level sets (which may be termed level surfaces in this case) are spheres when $c > 0$.
