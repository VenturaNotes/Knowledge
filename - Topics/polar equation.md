## Source [^1]
- An equation of a curve in polar coordinates is usually written in the form $r = f(\theta)$. Polar equations of some common curves are given in the above table.

| Curve                                   | Polar equation                                                           |
| :-------------------------------------- | :----------------------------------------------------------------------- |
| Circle $x^2 + y^2 = 1$                  | $r = 1$                                                                  |
| Half-line $y = x \, (x > 0)$            | $\theta = \pi/4$                                                         |
| Line $x = 1$                            | $r = \sec \theta \quad (-\frac{1}{2}\pi < \theta < \frac{1}{2}\pi)$      |
| Line $y = 1$                            | $r = \csc \theta \quad (0 < \theta < \pi)$                               |
| Circle $x^2 + y^2 - 2ax = 0 \, (a > 0)$ | $r = 2a \cos \theta \quad (-\frac{1}{2}\pi < \theta \le \frac{1}{2}\pi)$ |
| Circle $x^2 + y^2 - 2by = 0 \, (b > 0)$ | $r = 2b \sin \theta \quad (0 \le \theta < \pi)$                          |
| Cardioid See CARDIOID                   | $r = 2a(1 + \cos \theta) \quad (-\pi < \theta \le \pi)$                  |
| Conic See CONIC                         | $l/r = 1 + e \cos \theta \quad (\cos \theta \neq -1/e)$                  |

- Polar equations of standard curves
