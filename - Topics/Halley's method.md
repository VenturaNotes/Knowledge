## Source [^1]
- A method of solving an equation in one variable $f(x) = 0$ with a first approximation to the solution $x_0$ using the iteration$$ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n) - \left( \frac{f(x_n)f''(x_n)}{f'(x_n)} \right)}, \quad n = 0, 1, 2, \dots $$This method converges faster than Newton’s method, but more computation is required at each iteration, so neither method can claim to be more efficient.
