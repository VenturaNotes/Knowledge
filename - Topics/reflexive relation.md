## Source [^1]
- A relation $R$ defined on a set $S$ and having the property that$$\begin{aligned}& x R x \\ &\text {for all elements } x \text { in } S\end{aligned}$$The relation 'is the same age as' defined on the set of people is reflexive. Compare IRREFLEXIVE RELATION.
## Source[^2]
- A binary relation $\sim$ on a set $S$ is reflexive if $a \sim a$ for all $a$ in $S$. See EQUIVALENCE RELATION.
