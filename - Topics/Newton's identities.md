## Source [^1]
- Given a polynomial $a_n x^n + a_{n-1} x^{n-1} + \dots + a_0 = 0$, let $s_k$ denote the sum of the $k$th powers of the polynomial's roots. Then Newton's identities state for $k \ge 1$ that$$a_n s_k + a_{n-1} s_{k-1} + \dots + a_{n-k+1} s_1 + k a_{n-k} = 0.$$
- These identities recursively determine $s_k$ in terms of $s_{k-1}, \dots, s_1$. In these identities $a_r$ is understood to be 0 if $r < 0$. See also ELEMENTARY SYMMETRIC POLYNOMIALS.
