## Source [^1]
- In one, two, and three variables, functions in quadratic form are:$$\begin{align}&F(x) = ax^2\\&F(x,y) = ax^2 + by^2 + cxy\\&F(x,y,z) = ax^2 + by^2 + cz^2 + dxy + exz + fyz\end{align}$$
- Generally, if $\mathbf{x}$ is a column of $n$ variables and $\mathbf{A}$ is an $n \times n$ matrix then $\mathbf{x}^T\mathbf{Ax}$ will be in quadratic form. $\mathbf{A}$ can be chosen to be symmetric. See FORM.
