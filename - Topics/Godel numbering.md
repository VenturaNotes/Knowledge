## Source [^1]
- A Gödel numbering assigns to each finite word in a finite alphabet a unique natural number. As an example, if $A, B, \dots, Z$ are counted as $1, 2, \dots, 26$, then the word NUMBER would be assigned the number $2^{14} 3^{21} 5^{13} 7^2 11^5 13^{18}$. Using the primes $2, 3, 5, \dots$ in order and as $\text{N}$ is the $14\text{th}$ letter, $\text{U}$ the $21\text{st}$, etc. As prime factorization is unique, Gödel numbering is one-to-one.
