- If $\{(x_i, f_i)\}$, $i \ge 0$ is a given set of function values with $x_{i+1} = x_i + h$, $f_i = f(x_i)$, then the forward difference operator $\Delta$ is defined by$$\Delta f_i = f_{i+1} - f_i = f(x_{i+1}) - f(x_i).$$
