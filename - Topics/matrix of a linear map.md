## Source [^1]
- A linear map $T: V \to W$ between finite-dimensional vector spaces can be represented by a matrix if bases are chosen for $V$ and $W$. Given bases $v_1, \dots, v_m$ and $w_1, \dots, w_n$, the matrix for $T$, with respect to these bases, is the $n \times m$ matrix that sends the coordinate vector for $v$ (wrt the $v_i$) to the coordinate vector for $Tv$ (wrt the $w_i$). Precisely, this means the matrix has entries $a_{ij}$, where$$T(v_i) = \sum_{j=1}^{n} a_{ji} w_j.$$
- Any two matrices representing $T$ will be equivalent. See CHANGE OF BASIS, DIAGONALIZATION.
