## Source [^1]
- A non-zero vector $\mathbf{v}$ is a generalized eigenvector of a matrix $\mathbf{A}$, with generalized eigenvalue $\lambda$, if $(\mathbf{A} - \lambda\mathbf{I})^m \mathbf{v} = \mathbf{0}$ for some $m$. If a matrix is in Jordan normal form, then the basis used consists of generalized eigenvectors. Compare EIGENVALUE, EIGENVECTOR.
