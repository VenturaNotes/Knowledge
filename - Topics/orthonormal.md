## Source [^1]
- (orthonormal basis) An orthonormal set of vectors is a set of pairwise orthogonal unit vectors. Every finite-dimensional inner product space has an orthonormal basis. The canonical basis $\mathbf{i}, \mathbf{j}$, and $\mathbf{k}$ in $\mathbb{R}^3$ is orthonormal. See GRAM-SCHMIDT METHOD; compare COMPLETE ORTHONORMAL BASIS.
