## Source [^1]
- A square matrix $\mathbf{A}$ is nilpotent if $\mathbf{A}^n = \mathbf{0}$ for some $n$. Strictly triangular matrices are nilpotent. More generally, an element $x$ in a ring is nilpotent if $x^n = 0$ for some $n$.
