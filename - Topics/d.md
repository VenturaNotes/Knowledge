## Source [^1]
- The symbol used to denote the differential operator. So if $y$ is a real function of $x$ then $y' = \frac{dy}{dx}$ is the differential of $y$ with respect to $x$. Since it is $\frac{d}{dx}(y)$, when the second differential is taken, it is written as $\frac{d^2y}{dx^2}$ coming from $\frac{d}{dx}(\frac{dy}{dx})$.
	- See also EXTERIOR DERIVATIVE.
