- Without relying on other theorems for a result. For example, if $f(x) = x^2, f'(x) = 2x$ but to show this from first principles requires the following argument:$$\begin{align} &f'(x) = \lim_{\delta x \to 0} \frac{f(x + \delta x) - f(x)}{\delta x} \\& = \lim_{\delta x \to 0} \frac{x^2 + 2x\delta x + (\delta x)^2 - x^2}{\delta x} \\& = \lim_{\delta x \to 0} (2x + \delta x) = 2x \end{align}$$
