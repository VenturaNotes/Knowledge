## Source[^2]
- An ordered set with an unspecified but finite number ( $n$ ) of elements. See CARTESIAN PRODUCT, ORDERED PAIR.
## Source[^3]
- An $n$-tuple consists of $n$ objects normally taken in a particular order, denoted, for example, by $(x_1, x_2, \dots, x_n)$. The term is a generalization of a triple when $n = 3$ and a quadruple when $n = 4$. When $n = 2$ it is an ordered pair.
