## Source [^1]
- The real function, denoted by $\text{sgn}$, defined by$$\text{sgn}\, x = \begin{cases} -1, & \text{if } x < 0, \\ 0, & \text{if } x = 0, \\ 1, & \text{if } x > 0. \end{cases}$$
- The name and notation come from the fact that the value of the function depends on the sign of $x$. This notation is also used for the parity of permutations, that is,$$\text{sgn}\, \sigma = \begin{cases} 1 & \text{if } \sigma \text{ is even,} \\ -1 & \text{if } \sigma \text{ is odd.} \end{cases}$$
