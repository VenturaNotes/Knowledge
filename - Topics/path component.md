## Source [^1]
- An equivalence relation can be defined on a topological space (or metric space) $X$ by $x \sim y$ if there is a path between $x$ and $y$; that is, there is a continuous function $f: [0, 1] \to X$ such that $f(0) = x$ and $f(1) = y$. The equivalence classes of $\sim$ are the path components. A path-connected space is a space with a single path component.
