## Source [^1]
- (Lissajous figure) Named after Jules Antoine Lissajous (1822–80), a Lissajous curve is a planar curve that can be parameterized as$$x(t) = A_1 \sin(\omega_1 t + \epsilon), y(t) = A_2 \sin(\omega_2 t)$$
- The curve is closed if and only if $\omega_1/\omega_2$ is *rational.
