## Source [^1]
- A polynomial $F(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_1 x + a_0$ with integer coefficients is irreducible over the rationals if a prime number $p$ exists such that:
	- (i) $p$ divides each $a_i$ for $i \neq n$;
	- (ii) $p$ does not divide $a_n$;
	- (iii) $p^2$ does not divide $a_0$.
- For example, $x^n - 2$ is irreducible for all values of $n$. The criterion can also be usefully applied to cyclotomic polynomials. It cannot immediately be applied to $x^2 + x + 1$, but if we set $x = u + 1$, then we obtain $u^2 + 3u + 3$; this second polynomial is irreducible by the criterion (with $p = 3$) and, as it is irreducible, so is $x^2 + x + 1$.
