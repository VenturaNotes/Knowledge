## Source [^1]
- (Friedrich Ferdinand) (1871–1953) German mathematician considered the founder of axiomatic set theory. In 1908, he formulated a set of axioms for set theory, which attempted to overcome problems such as that posed by Russell's paradox. These, with modifications by Fraenkel around 1922, have been the foundation on which much subsequent work in the subject has been built.
