## Source [^1]
- (minimum) In a partially ordered set $(S, \le)$, a minimum is an element $m$ such that $m \le s$ for all $s \in S$. A minimal element is an element $M$ such that there is no element $s$ with $s < M$. So a minimum is a minimal element, but a minimal element need not be a minimum.
