## Source [^1]
- (of a matrix game) Suppose that, in the matrix game given by the $m \times n$ matrix $[a_{ij}]$, the mixed strategies $\mathbf{x}$ and $\mathbf{y}$ for the two players are given by $\mathbf{x} = (x_1, x_2, \dots, x_m)$, and $\mathbf{y} = (y_1, y_2, \dots, y_n)$. The expectation $E(\mathbf{x}, \mathbf{y})$ is given by$$E(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^m \sum_{j=1}^n x_i a_{ij} y_j.$$
- If $\mathbf{A} = [a_{ij}]$, then $E(\mathbf{x}, \mathbf{y}) = \mathbf{x} \mathbf{A} \mathbf{y}^T$. The expectation can be said, loosely, to give the average payoff each time when the game is played many times with the two players using these mixed strategies.
