## Source [^1]
- Given a function $f(x)$ on the interval $0 < x < L$, the Fourier sine series is defined as$$\begin{align}&\sum_{n=1}^{\infty} b_n \sin\left(\frac{n\pi x}{L}\right), \\&\text{where}\quad b_n = \frac{2}{L} \int_{0}^{L} f(x) \sin\left(\frac{n\pi x}{L}\right) \text{ dx}.\end{align}$$
- This defines an odd function of period $2L$.
