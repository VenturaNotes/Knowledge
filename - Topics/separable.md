### Of A Function
- A function which can be written so that the variables are separated additively or multiplicatively, for example $2x^2y+4y = 2y(x^2+2)$ or $x^2+y^2-4x+6y+13 = (x-2)^2+(y+3)^2$.
### Of a Space
- (of a space) A topological space (or metric space) is separable if it has a countable dense subset (see DENSE SET). So $\mathbb{R}$ is separable, as $\mathbb{Q}$ is countable and its closure is $\mathbb{R}$.
