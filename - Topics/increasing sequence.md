## Source [^1]
- A sequence $a_1, a_2, a_3, \dots$ is increasing if $a_m \le a_n$ whenever $m \le n$, and strictly increasing if $a_m < a_n$ whenever $m < n$. This is equivalent to the function $i \mapsto a_i$ being increasing or strictly increasing. See also NESTED SETS.
