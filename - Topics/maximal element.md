## Source [^1]
- (maximum) In a partially ordered set $(\mathcal{S}, \le)$, a maximum is an element $m$ such that $s \le m$ for all $s \in \mathcal{S}$. A maximal element is an element $M$ such that there is no element $s$ with $M < s$. So a maximum is a maximal element, but a maximal element need not be a maximum.
