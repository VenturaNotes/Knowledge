## Source [^1]
- A vector $\mathbf{p}$ is coplanar with non-zero, non-parallel vectors $\mathbf{a}$ and $\mathbf{b}$ if and only if there exist scalars $\lambda$ and $\mu$ such that $\mathbf{p} = \lambda \mathbf{a} + \mu \mathbf{b}$. Note that this is equivalent to the three points with position vectors $\mathbf{a}, \mathbf{b}, \mathbf{p}$, together with the origin, being coplanar. See LINEARLY DEPENDENT.
