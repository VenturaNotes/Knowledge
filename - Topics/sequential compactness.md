## Source [^1]
- A topological space (or metric space) $X$ is sequentially compact if every sequence in $X$ has a subsequence which converges in $X$. A metric space is compact if and only if it is sequentially compact, but this is not generally true for topological spaces. See BOLZANO-WEIERSTRASS THEOREM.
