## Source [^1]
- A real function $f$ is decreasing on an interval $I$ if $f(x_1) \geq f(x_2)$ whenever $x_1$ and $x_2$ are in $I$ with $x_1 \leq x_2$. Also, $f$ is strictly decreasing if $f(x_1) > f(x_2)$ whenever $x_1 < x_2$.
