## Source [^1]
- A vector potential for a vector field $\mathbf{F}$ is a vector field $\mathbf{A}$ such that $\mathbf{F} = \text{curl} \mathbf{A}$. If such a vector field exists, then $\text{div} \mathbf{F} = 0$. Conversely, if $\text{div} \mathbf{F} = 0$, then the question of whether $\mathbf{F}$ has a vector potential relates to the topology of the domain on which $\mathbf{F}$ is defined. See POTENTIAL.
