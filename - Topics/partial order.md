## Source [^1]
- A partial order on a set $X$, usually denoted $\le$, is a binary relation which is reflexive, anti-symmetric, and transitive. Examples include $\subseteq$ on the power set of a set and divides on the set of positive integers. See also TOTAL ORDER.
