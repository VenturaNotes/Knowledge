## Source [^1]
- A function $f\left(x_{1}, x_{2}, \ldots x_{n}\right)$ whose value is unaltered by any permutation of its $n$ variables. Such functions arise repeatedly in switching theory.
## Source[^2]
- A function $f$ on $n$ variables $x_1, x_2, \dots, x_n$ is symmetric if$$ f(x_{\sigma(1)}, x_{\sigma(2)}, \dots, x_{\sigma(n)}) = f(x_1, x_2, \dots, x_n) $$for all permutations $\sigma$ of $n$ variables. See ELEMENTARY SYMMETRIC POLYNOMIAL.
