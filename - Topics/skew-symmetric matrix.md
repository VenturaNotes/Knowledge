## Source[^2]
- Let $\mathbf{A}$ be the square matrix $[a_{ij}]$. Then the matrix $\mathbf{A}$ is skew-symmetric, or antisymmetric, if $\mathbf{A}^T = -\mathbf{A}$ (see TRANSPOSE); that is to say, if $a_{ij} = -a_{ji}$ for all $i$ and $j$. It follows that in a skew-symmetric matrix the entries in the main diagonal are all zero: $a_{ii} = 0$ for all $i$.
