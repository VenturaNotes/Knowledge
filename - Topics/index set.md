## Source [^1]
- A set $S$ may consist of elements, each of which corresponds to an element of a set $I$. Then $I$ is the index set, and $S$ is said to be indexed by $I$. For example, the set $S$ may consist of elements $a_i$, where $i \in I$. This is written $S = \{a_i \mid i \in I\}$. A denumerable set can be indexed by the set of natural numbers.
