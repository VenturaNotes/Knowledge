## Source [^1]
- An iterative method of approximating the square root of a number. If $\sqrt{k}$ is required, and $x_0$ is an initial approximation, then $x_{n+1} = \frac{(x_n + \frac{k}{x_n})}{2}, n = 0, 1, 2, \dots$ will converge to the square root of $k$. For example, to calculate the square root of $5$, using a first approximation of $2$, will give $x_1 = \frac{(2 + 2.5)}{2} = 2.25, x_2 = 2.23611111 \dots, x_3 = 2.236067978 \dots, x_4 = 2.236067978 \dots$ and $\sqrt{5} = 2.236067978 \dots$. So this method has found the square root to $8$ dp after only three iterations.
