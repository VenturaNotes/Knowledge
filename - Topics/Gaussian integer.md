## Source [^1]
- A complex number whose real and imaginary parts are both integers, so $z = a + ib$ is a Gaussian integer if $a, b \in \mathbb{Z}$. The set of Gaussian integers is denoted $\mathbb{Z}[i]$. They form a Euclidean domain with Euclidean function $d(a + ib) = a^2 + b^2$.
